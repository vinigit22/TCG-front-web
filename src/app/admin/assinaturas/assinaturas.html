Modelo sugerido para o backend

O mínimo para esta tela funcionar com dados reais

Tabelas

plano (id, nome, preco_mensal, max_torneios_ativos,
       max_jogadores, ativo)

assinatura (id, loja_id, plano_id, status,
            inicio_em, proxima_cobranca, cancelada_em)
  status: TESTE | ATIVA | ATRASADA | CANCELADA

Rotas

GET  /planos                 (público)
GET  /assinaturas?lojaId=    (admin; loja vê a dela)
PUT  /assinaturas/{id}       (admin: trocar plano/status)
GET  /lojas/{id}/assinatura  (loja logada)

Com isso, o limite do plano Gratuito (1 torneio ativo, 16 jogadores) pode ser checado no TorneioService.
